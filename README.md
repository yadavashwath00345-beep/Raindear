# Raindear 🌅

A premium PWA for Shayari, Music, Facts, Quotes, Nature & Games.

## Deploy to GitHub Pages (automatic)

1. Push this entire folder to your GitHub repository (e.g. `github.com/yourname/raindear`)
2. Go to **Settings → Pages**
3. Under **Source**, select **GitHub Actions**
4. Push any change — GitHub will auto-build and deploy!
5. Your site will be live at: `https://yourname.github.io/raindear/`

## Run locally

```bash
pnpm install
pnpm run dev
```

## Build manually

```bash
pnpm run build:github
# Built files will be in ./dist/
```

## Add Google AdSense

After AdSense approval, open `index.html` and paste your script tag
